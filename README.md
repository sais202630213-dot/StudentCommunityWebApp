서울인공지능고등학교 학생 커뮤니티

서울인공지능고등학교 학생들이 학교 생활과 관련된 정보를 공유하고 소통할 수 있도록 제작한 커뮤니티 웹사이트입니다.

📌 프로젝트 소개

학생들이 게시글을 작성하고 다른 학생들의 게시글을 확인할 수 있는 학교 커뮤니티를 목표로 제작했습니다.

게시판을 중심으로 다양한 정보를 공유할 수 있으며, 사용자가 페이지를 이동하거나 게시글을 관리하는 등 동적인 웹 기능을 제공합니다.

✨ 주요 기능

📝 게시글 관리
- 게시글 작성
- 게시글 조회
- 게시글 수정
- 게시글 삭제
- 게시글 목록 확인

💬 커뮤니티
- 학생 간 정보 공유
- 학교생활 관련 게시글 확인
- 게시판을 통한 자유로운 소통

🔍 게시판 기능
- 게시글 목록 표시
- 게시글 상세 내용 확인
- 게시글 작성 및 관리
- 페이지 간 이동

🔄 동적 기능
- 페이지 이동
- 페이지 내부의 콘텐츠 변화
- 게시글 데이터 CRUD(Create, Read, Update, Delete)

🛠️ 사용 기술

- React
- TypeScript
- Vite
- Tailwind CSS
- GitHub Pages
- GitHub Actions
